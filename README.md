## Structure of Each Solution

Every problem includes:
1. **Problem Statement** — what the problem asks
2. **Intuition** — how to think about it
3. **Approaches** — brute force → optimal, with time/space tradeoffs
4. **Dry Run** — step-by-step walkthrough on a real example with variable states
5. **Complexity Analysis** — time + space
6. **Edge Cases** — what to discuss in an interview
7. **Interview Tips** — what interviewers look for + common follow-ups
8. **Code** — clean Python 3 with inline comments
9. **Test Cases** — 5+ test cases with assertions

## Tech Stack

- **Language:** Python 3
- **Testing:** Each solution includes runnable test cases with assertions
- **Format:** One `.py` file per problem

## How to Use This Repo

1. **Learn the pattern** — read the Intuition + Approach sections first
2. **Dry run by hand** — follow the step-by-step walkthrough
3. **Code it yourself** — try before reading the solution
4. **Run tests** — `python3 <file>.py` to verify
5. **Review edge cases** — these are what get you hired

> Solve one category at a time. Master patterns, not memorization.
