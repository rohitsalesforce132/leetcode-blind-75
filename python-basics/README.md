# Python From Zero — Complete Fundamentals Guide

> **For:** Programmers who want to truly *understand* Python from absolute basics to advanced.
> **Style:** Real-world analogies, visual diagrams, runnable code. No jargon without explanation.

## How to Use This Guide

1. Read each chapter in order — each builds on the previous
2. Run every code example: `python3 01-variables-and-types.py`
3. Do NOT skip the "Mental Model" boxes — they are the actual lesson
4. Every chapter ends with exercises (answers at the bottom)
